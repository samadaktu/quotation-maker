# QuoteCraft - Professional Quotation Maker

A fully functional, professional quotation maker web application built with React + Vite.

## Features

- 📝 **Company & Client Details** — Complete sender and recipient information
- 🖼️ **Logo Upload** — Drag & drop logo with live preview
- 📋 **Line Items** — Add/remove items with auto-calculated totals
- 💰 **Smart Calculations** — Subtotal, discount, tax, and grand total
- 🌍 **Multi-Currency** — Support for USD, EUR, GBP, INR, AED, and more
- 👁️ **Live Preview** — Real-time A4 document preview
- 📄 **PDF Download** — High-quality PDF generation
- 🏦 **Bank Details** — Payment information section
- 📱 **Fully Responsive** — Desktop, tablet, and mobile support

## Tech Stack

- **React 18** with Vite
- **Custom CSS** with CSS Variables (no UI framework)
- **html2canvas + jsPDF** for PDF generation
- **react-icons** for icons

## Installation

```bash
git clone https://github.com/your-username/quotation-maker.git
cd quotation-maker
npm install
npm run dev
```

## Usage

1. Fill in your company details and upload a logo
2. Enter client information
3. Add line items with quantities, prices, tax rates, and discounts
4. Preview the quotation in real-time
5. Download as a professional PDF
